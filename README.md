# Spinger

Consent-based phone book — search people who are on Spinger, invite those who aren’t, and connect only when both sides agree.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s in this UI

Optimized contacts screen (compact list, not big cards):

- Compact header: **Spinger** + search + add
- Segmented control: **My contacts** / **Spinger network**
- Search + filters: **Recent** | **A–Z** | **Not on Spinger**
- Status labels: On Spinger / Not on Spinger / Invite sent
- Quick actions: Call, Message, Invite
- Bottom nav: Feed, Spinger, Chat, Insights
